CSS Position Property Showroom

Scroll the webpage vertically to see how different boxes react to the viewport layout flow.

Static Position Default normal flow layout. Ignores top/left properties.
Relative Position Moved from its original location. Space remains reserved.
Absolute Position Removed from flow. Positioned relative to parent container.
Fixed Position Locked to the browser viewport window. Never moves during scrolling.
Sticky Position Acts normal until scrolled to top, then locks in place.
