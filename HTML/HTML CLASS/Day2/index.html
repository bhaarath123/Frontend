HTML Tags

Types of HTML tags include block-level, inline, formatting, and interactive elements.

Block Example

Starts on a new line. Takes full width by default. Can contain other block and inline elements.
Used for page layout and content structure.

Inline Example

Does not start on a new line.
Takes up only as much width as necessary.
Can contain other inline elements.
Used for styling and formatting text.

Formatting Example

Used to change the appearance of text.
Can be applied to both block and inline elements.
Examples include bold, italic, underline, and highlight.

Interactive Example

Used to create interactive elements such as forms, buttons, and links.
Can contain other block and inline elements. Used for page layout and content structure.
