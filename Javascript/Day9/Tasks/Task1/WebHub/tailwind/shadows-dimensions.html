Shadows & Dimensions

1. What is it?

Dimensions control elements width (tw-w-*) and height (tw-h-*). Shadows (tw-shadow-*) apply depth to elements using blur ranges.

2. Why is it important?

Controlling card dimensions and shadows is critical. Shadow levels build layout depth, and width constraints keep text blocks readable.

3. Syntax & Basic Example

<div class="tw-w-full tw-max-w-md tw-h-64 tw-shadow-lg tw-bg-white">
  Shadow card container.
</div>

Basic description: A shadowed box with size: `<div class="tw-w-32 tw-h-32 tw-shadow">Size Box</div>`.

4. Code & Interactive Rendered Output

    <p class="tw-text-xs tw-text-slate-500 tw-mt-1">This card has width boundaries and a drop shadow.</p>
</div>

5. Line-by-Line Explanation

  • tw-shadow-md: Applies a medium drop shadow effect.
  • tw-max-w-xs: Restricts the card width to a maximum of 20rem (320px).
  • tw-p-6: Adds padding space inside the card.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
tw-shadow-* Adds box drop shadows (shadow-sm, shadow-md, shadow-lg, shadow-xl, shadow-none).
tw-w-* Sets element width using percentages (w-1/2, w-full) or relative units.
tw-h-* Sets element height using relative units (h-32, h-64, h-screen).

7. Real-World Use

Portals display dashboards widgets using shadowed cards, and set viewport heights using h-screen to align overlays.

Best Practices

  • Use max-w-* classes to restrict content widths on wide screens.
  • Use shadow-sm or shadow-md for subtle, professional layout depth.

Common Mistakes

  • Using fixed height classes (like h-64) on text cards, which causes text to overflow container boundaries on small screens. Use min-h-* instead.
  • Using overly dark shadow utilities, making the interface look unpolished.

9. Tech Screening Question

Q: What is the difference between tw-w-screen and tw-w-full in Tailwind?
Answer:

The tw-w-screen class sets the element width to 100vw (100% of the viewport width), which can bypass parent containers. The tw-w-full class sets the element width to 100% of its parent container's width.

Explanation:

Use w-full to keep elements within grids; use w-screen for full-width overlays.

Overlay modal: w-screen. Card inside grid: w-full.

10. Quick Revision

Set widths with tw-w-* and heights with tw-h-*. Add depth to containers using shadow levels (tw-shadow-*), and restrict widths with max-w-* classes.
