Tailwind CSS Introduction

1. What is it?

Tailwind CSS is a utility-first CSS framework. Unlike Bootstrap, which provides pre-designed components (like cards or navbars), Tailwind provides low-level utility classes that you combine to build completely custom designs directly in your HTML.

2. Why is it important?

Tailwind eliminates writing custom CSS selectors. You build unique designs without leaving your HTML, maintaining clean files with zero unused stylesheet bloating.

3. Syntax & Basic Example

<!-- Tailwind Component Markup -->
<div class="tw-bg-white tw-shadow-md tw-rounded-lg tw-p-6">
  <h2 class="tw-text-xl tw-font-bold tw-text-gray-800">Custom Title</h2>
</div>

Basic description: A styled Tailwind box: `<div class="tw-bg-blue-500 tw-p-4 tw-rounded">Text</div>`.

4. Code & Interactive Rendered Output

tailwind live sandbox
<div class="tw-bg-slate-100 tw-p-4 tw-rounded-lg tw-shadow-sm tw-max-w-xs">
    <h5 class="tw-text-indigo-600 tw-font-semibold tw-text-base">Utility Build</h5>
    <p class="tw-text-slate-600 tw-text-sm tw-mt-1">Tailwind uses specific, single-purpose classes.</p>
    <button class="tw-mt-3 tw-bg-indigo-600 hover:tw-bg-indigo-700 tw-text-white tw-text-xs tw-font-bold tw-py-2 tw-px-4 tw-rounded">Learn more</button>
</div>
Live Output & Execution Preview
Utility Build

Tailwind uses specific, single-purpose classes.

Expected Layout / Behavior: A styled grey card container containing an indigo title, slate-grey text, and a blue button that turns dark blue on hover.

5. Line-by-Line Explanation

  • tw-bg-slate-100: Sets a light slate background color.
  • tw-p-4, tw-mt-1: Spacing padding and margins.
  • tw-text-indigo-600, tw-text-sm: Sizing and colors for text.
  • hover:tw-bg-indigo-700: State variant class that changes background color on mouse hover.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
Utility-first Building designs using low-level utility classes directly in the markup.
Prefix variants Appending state prefixes (hover:, focus:) to handle interactive states.
Responsive prefixes Appending screen prefixes (sm:, md:) to handle responsive breakpoints.

7. Real-World Use

Modern SaaS platforms and custom portfolios use Tailwind CSS to build highly unique designs that differ from standard Bootstrap templates.

Best Practices

  • Refactor repeated patterns into reusable templates (like partials) to keep HTML files clean.
  • Use Tailwind's config file to customize brand colors, spacing scales, and breakpoints.

Common Mistakes

  • Expecting class names to match Bootstrap names (e.g., writing 'card' or 'btn', which do not exist in Tailwind).
  • Cluttering HTML files with hundreds of class overrides without refactoring repeated patterns into reusable templates.

9. Tech Screening Question

Q: What is utility-first CSS, and how does it differ from component frameworks like Bootstrap?
Answer:

Utility-first CSS means building layouts using low-level, single-purpose classes (e.g. for margins, font sizes, colors) directly in the HTML. Component frameworks like Bootstrap provide pre-designed UI elements (like cards or alerts). Tailwind gives you the building blocks to build any design, whereas Bootstrap gives you pre-packaged components that are harder to customize.

Explanation:

Tailwind doesn't impose a visual style; it acts as a styling tool inside your HTML.

Bootstrap: .btn .btn-primary. Tailwind: .tw-bg-blue-600 .tw-text-white .tw-px-4 .tw-py-2 .tw-rounded.

10. Quick Revision

Tailwind CSS is a utility-first CSS framework. It provides low-level utility classes that you apply directly to HTML tags, giving you complete design freedom without forcing a visual template.
