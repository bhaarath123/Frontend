Tailwind Flexbox

1. What is it?

Tailwind Flexbox utilities configure flex layout structures directly in the HTML markup. They manage direction, wrapping, justification, alignments, and gap spacing.

2. Why is it important?

Avoids writing custom flex selectors. You align lists and center elements side-by-side without leaving the HTML file.

3. Syntax & Basic Example

<div class="tw-flex tw-flex-row tw-justify-between tw-items-center tw-gap-4">
  <div>Logo</div>
  <div>Nav Links</div>
</div>

Basic description: Perfect centering in Tailwind: `<div class="tw-flex tw-justify-center tw-items-center">Center</div>`.

4. Code & Interactive Rendered Output

tailwind live sandbox
<div class="tw-flex tw-flex-col sm:tw-flex-row tw-gap-3 tw-bg-slate-100 tw-p-4 rounded">
    <div class="tw-flex-1 tw-bg-white tw-p-3 tw-rounded text-center font-bold text-indigo-600 border">Item 1</div>
    <div class="tw-flex-1 tw-bg-white tw-p-3 tw-rounded text-center font-bold text-indigo-600 border">Item 2</div>
</div>

Expected Layout / Behavior: Two white boxes displayed side-by-side on desktop, but stacked vertically on mobile screens.

5. Line-by-Line Explanation

  • tw-flex: Sets display: flex on container.
  • tw-flex-col, sm:tw-flex-row: Stacks elements vertically on mobile, but aligns them horizontally on tablets and desktops.
  • tw-flex-1: Sets flex-grow, flex-shrink, and flex-basis, making items share container space equally.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
tw-flex-row / tw-flex-col Sets flex item direction (row, column).
tw-justify-* Aligns items along the main axis (justify-start, justify-center, justify-between).
tw-items-* Aligns items along the cross axis (items-start, items-center, items-stretch).

7. Real-World Use

Navbar components, sidebar listings, button clusters, and form groups are built using Tailwind flex utilities.

Best Practices

  • Use responsive direction classes (flex-col md:flex-row) to build layouts that adapt to mobile.
  • Use flex-1 to distribute space equally among flex items.

Common Mistakes

  • Adding justification (tw-justify-center) or alignment (tw-items-center) classes to elements that do not have the display flex (tw-flex) class.
  • Forgetting that gap classes require the display flex or grid property to function.

9. Tech Screening Question

Q: How do you build a responsive card layout that stacks on mobile but aligns horizontally on desktop using Tailwind?
Answer:

You configure this by combining tw-flex-col (the mobile default vertical stack) with a responsive breakpoint override like md:tw-flex-row (row alignment on medium screens and wider) on the flex container element.

Explanation:

This allows you to control responsive layout behavior directly in the HTML without writing media queries in custom CSS files.

<div class='tw-flex tw-flex-col md:tw-flex-row tw-gap-4'>...</div>

10. Quick Revision

Use tw-flex to activate flexbox. Control spacing using tw-gap-*. Use justification (tw-justify-*) and alignment (tw-items-*) classes to manage alignment.
