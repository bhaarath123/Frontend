Typography

1. What is it?

Tailwind typography classes control font size, weight, colors, line height, alignment, and styles directly in the HTML tag.

2. Why is it important?

Saves you from writing custom text classes. You can make text small and muted (tw-text-sm tw-text-gray-500) or bold and large (tw-text-3xl tw-font-bold) instantly.

3. Syntax & Basic Example

<h1 class="tw-text-3xl tw-font-extrabold tw-tracking-tight tw-text-slate-900">
  Headline Content
</h1>

Basic description: A bold, large heading: `<h1 class="tw-text-2xl tw-font-bold">Title</h1>`.

4. Code & Interactive Rendered Output

tailwind live sandbox
<div class="tw-p-3 bg-white border rounded">
    <h3 class="tw-text-xl tw-font-bold tw-text-indigo-600">Heading 3</h3>
    <p class="tw-text-sm tw-text-slate-500 tw-leading-relaxed tw-mt-2">This is a description paragraph with relaxed line height and muted grey text styling.</p>
</div>
Live Output & Execution Preview

Heading 3

This is a description paragraph with relaxed line height and muted grey text styling.

Expected Layout / Behavior: A card displaying a bold indigo title and a paragraph with spacious, readable grey text copy.

5. Line-by-Line Explanation

  • tw-text-xl: Sets font size to 1.25rem (20px).
  • tw-font-bold: Sets font weight to 700.
  • tw-text-indigo-600: Applies blue text color.
  • tw-leading-relaxed: Increases line-height to 1.625, boosting article readability.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
tw-text-* Sets font size (text-xs, text-sm, text-lg, text-3xl).
tw-font-* Sets font weight (font-light, font-normal, font-bold, font-black).
tw-leading-* Sets line height (leading-tight, leading-normal, leading-relaxed).

7. Real-World Use

Blogs, headers, landing details, and settings labels rely on typography utilities. Tailwind's typography plugin (@tailwindcss/typography) is widely used to style raw markdown content.

Best Practices

  • Use relative units (rem) for sizing to ensure accessibility.
  • Set readable line heights (leading-relaxed) for body paragraphs.

Common Mistakes

  • Using heading sizing classes without pairing them with correct HTML tags, hurting document hierarchy.
  • Forgetting that typography color configurations (tw-text-blue-500) require color values (like 500) and cannot be just 'tw-text-blue'.

9. Tech Screening Question

Q: What are font weight and sizing utilities in Tailwind, and how do you configure line height?
Answer:

In Tailwind, font sizes are set using tw-text-{size} (e.g. tw-text-sm, tw-text-lg, tw-text-4xl). Font weights are set using tw-font-{weight} (e.g. tw-font-normal, tw-font-bold, tw-font-black). Line height is configured using the leading-{height} classes (e.g. tw-leading-tight, tw-leading-relaxed).

Explanation:

Pairing size classes with proportional line height is critical for text layouts.

tw-text-2xl tw-leading-snug (large text with tight line spacing).

10. Quick Revision

Manage typography inside HTML tags using text size (tw-text-*), font weights (tw-font-*), and line height (tw-leading-*) utility classes.
