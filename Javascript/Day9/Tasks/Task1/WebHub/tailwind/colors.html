Tailwind Colors

What is Tailwind Colors?

Tailwind CSS includes a pre-designed, curated color palette. It supports text color (tw-text-*), background color (tw-bg-*), border color (tw-border-*), and accent colors across several color weight levels.

Why is it used?

Using a prebuilt color palette prevents websites from looking messy. It ensures that color selections look professional and have consistent shading adjustments.

Code & Output Example

tailwind editor
<div class="tw-flex tw-flex-col tw-gap-2">
    <div class="tw-bg-emerald-100 tw-text-emerald-800 tw-p-2 tw-rounded">Success Alert</div>
    <div class="tw-bg-rose-100 tw-text-rose-800 tw-p-2 tw-rounded">Danger Alert</div>
</div>
Visual Preview
Success Alert
Danger Alert

Code Explanation

  • tw-bg-emerald-100: Soft green background tint.
  • tw-text-emerald-800: High-contrast green text.
  • tw-bg-rose-100: Soft red background tint.
  • tw-text-rose-800: High-contrast red text.

Important Points

  • Color values run from 50 (lightest tint) to 950 (darkest shade) in steps of 100.
  • Standard palettes include: slate, gray, zinc, neutral, stone, red, orange, amber, yellow, lime, green, emerald, teal, cyan, sky, blue, indigo, violet, purple, fuchsia, pink, rose.
  • Transparent and current colors are supported.

Common Mistakes

  • Mixing too many conflicting color palettes (e.g. using emerald, rose, sky, orange, and fuchsia elements together), making the site look unpolished.
  • Forgetting the shade suffix (e.g. writing tw-bg-indigo instead of tw-bg-indigo-600).

Real-World Usage

Design systems configure theme maps. Swapping values from slate-900 to slate-50 shifts layouts from dark structures to light layouts.

Interview Question

Q: How does Tailwind's color numeric system work?
Answer:

Tailwind's colors are divided into numeric steps from 50 to 950. 50 is the lightest tint (useful for backgrounds), 500 is the base color (useful for buttons), and 900/950 are the darkest shades (useful for text and headings).

Explanation:

This granular spacing allows developers to build coordinated, high-contrast, and accessible color structures easily.

tw-bg-indigo-50 (light bg) -> tw-bg-indigo-600 (button) -> tw-bg-indigo-950 (dark border).
