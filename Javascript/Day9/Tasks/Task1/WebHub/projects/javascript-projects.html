Project: Interactive Calculator Intermediate
Project Objective:

Build an interactive digital calculator supporting addition, subtraction, multiplication, division, and clear screen operations.

Requirements:
  • Clean button grid layout
  • Event listeners for number and operator clicks
  • Live calculation display screen
Starter Skeleton:
<!-- Calculator UI and Script -->

Expected: A working interactive calculator component.

View Complete Solution Code 
<div id="calc" class="p-3 bg-dark text-white rounded" style="max-width: 260px;">
  <input type="text" id="calc-screen" class="form-control mb-2 text-end" readonly value="0">
  <div class="d-grid gap-2" style="grid-template-columns: repeat(4, 1fr);">
    <button class="btn btn-secondary" onclick="press('7')">7</button>
    <button class="btn btn-secondary" onclick="press('8')">8</button>
    <button class="btn btn-secondary" onclick="press('9')">9</button>
    <button class="btn btn-warning" onclick="press('/')">/</button>
    <button class="btn btn-danger" onclick="clearCalc()">C</button>
    <button class="btn btn-secondary" onclick="press('0')">0</button>
    <button class="btn btn-success" onclick="calculate()">=</button>
    <button class="btn btn-warning" onclick="press('+')">+</button>
  </div>
</div>
<script>
let exp = '';
function press(v) { exp += v; document.getElementById('calc-screen').value = exp; }
function clearCalc() { exp = ''; document.getElementById('calc-screen').value = '0'; }
function calculate() { try { exp = String(eval(exp)); document.getElementById('calc-screen').value = exp; } catch(e) { document.getElementById('calc-screen').value = 'Error'; } }
</script>
