Developer Cheat Sheets

A quick-reference guide for HTML5 tags, CSS3 selectors, Bootstrap, Tailwind, and JavaScript APIs.

HTML5 Quick Reference
  • Common Tags:
    <html>, <head>, <body>, <h1>-<h6>, <p>, <div>, <span>
  • Forms:
    <form>, <label>, <input>, <textarea>, <select>, <button>
  • Tables:
    <table>, <tr>, <th>, <td>, <thead>, <tbody>
  • Semantic HTML:
    <header>, <nav>, <main>, <section>, <article>, <footer>
CSS3 Quick Reference
  • Selectors:
    .class, #id, tag, :hover, :focus, ::before, ::after
  • Box Model:
    width, height, padding, border, margin, box-sizing: border-box
  • Flexbox:
    display: flex, justify-content, align-items, flex-direction, gap
  • Grid:
    display: grid, grid-template-columns, gap, grid-column: span X
Bootstrap 5 Quick Reference
  • Grid:
    .container, .row, .col-*, .col-md-6, .g-3
  • Components:
    .btn, .card, .navbar, .alert, .badge, .modal
  • Utilities:
    .p-3, .mb-4, .text-center, .d-flex, .bg-primary
Tailwind CSS Quick Reference
  • Layout & Spacing:
    tw-p-4, tw-m-2, tw-gap-4, tw-flex, tw-grid, tw-grid-cols-3
  • Colors & Typography:
    tw-bg-slate-900, tw-text-white, tw-text-xl, tw-font-bold
  • Variants:
    hover:tw-bg-indigo-600, focus:tw-ring-2, dark:tw-bg-slate-900
JavaScript (ES6+) Quick Reference
  • Variables & Types:
    const, let, typeof. Primitives: String, Number, Boolean, BigInt, Undefined, Null, Symbol.
  • Operators:
    Strict equality: ===, !==. Logical: &&, ||, !. Ternary: cond ? a : b.
  • Array Methods:
    .push(), .pop(), .slice(), .splice(), .map(), .filter(), .reduce(), .find(), .includes()
  • Object Methods:
    Object.keys(), Object.values(), Object.entries(), JSON.stringify(), JSON.parse()
  • DOM Methods:
    document.getElementById(), document.querySelector(), .textContent, .classList.toggle(), .addEventListener()
  • ES6+ Features:
    Arrow functions () => {}, Destructuring const {a} = obj, Spread [...arr], Template literals `${val}`, async/await
  • Storage & Timing:
    localStorage.setItem(k, v), localStorage.getItem(k), setTimeout(fn, ms), setInterval(fn, ms)
