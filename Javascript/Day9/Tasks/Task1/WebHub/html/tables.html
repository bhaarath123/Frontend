HTML Tables & Layout grids

1. What is it?

Tables arrange data in rows and columns. They are constructed using

, (row), & : Grouping tags separating header rows from content rows.
  • colspan='2': Merges the header cell across two columns horizontally.
  • border-collapse: CSS style that collapses adjacent borders into single lines.

    • 6. Key Properties, Methods & Syntax

    (header), and (cell) tags, supported by cell-merging parameters (colspan, rowspan).

    2. Why is it important?

    Tabular data is unreadable in raw text runs. Grid structures organize pricing lists, schedules, and metrics databases into readable layouts.

    3. Syntax & Basic Example

    <table>
  <tr>
    <th>Header</th>
  </tr>
  <tr>
    <td>Data</td>
  </tr>
</table>

    Basic description: A simple two-column single row table: `<table><tr><td>A</td><td>B</td></tr></table>`.

    4. Code & Interactive Rendered Output

    Expected Layout / Behavior: A bordered data grid displaying one header row with a merged right cell, and one data row below.

    5. Line-by-Line Explanation
    Property / Method / Tag Description
    colspan Attribute merging cells across columns.
    rowspan Attribute merging cells across rows.
    caption Optional tag defining the title description of the table.

    7. Real-World Use

    Compare plans (Free vs Pro packages) and dashboards data metrics utilize tables to format grids.

    Best Practices

    • Always wrap tables in an overflow container to prevent horizontal scrollbars on mobile devices.
    • Use caption elements to describe table contents.

    Common Mistakes

    • Using HTML tables to design page layouts (navbars, column grids). This is bad for SEO, rendering speed, and mobile responsiveness.
    • Miscounting column merges, warping the grid layout.

    8. Interactive Practice Challenge

    Create a table with two header columns 'Plan' and 'Price'. Add a second row where the first cell spans both columns showing text 'Unavailable'.

    Objective: Practice using colspan merging.

    Instructions: Combine th, td, and colspan elements.

    <!-- Write pricing table -->
    Reveal Hint

    Use colspan='2' on the td element in the second row.

    Reveal Solution 
    <table border="1">
    <tr>
        <th>Plan</th>
        <th>Price</th>
    </tr>
    <tr>
        <td colspan="2">Unavailable</td>
    </tr>
</table>

    9. Tech Screening Question

    Q: Why is it bad practice to use tables for website layouts?
    Answer:

    Using tables for website layouts hurts web accessibility (screen readers read cells in a linear order, which breaks layouts), makes responsive styling extremely difficult, and slows down browser rendering because browsers calculate table dimensions after loading all cells.

    Explanation:

    Modern responsive layouts should be built using div or semantic wrappers styled with Flexbox and CSS Grid.

    Incorrect: Using table rows for navbars. Correct: Using nav/ul tags with flex styles.

    10. Quick Revision

    Use tables for tabular data, not layouts. Manage cell span columns/rows using colspan/rowspan, and group records using thead, tbody, and tfoot.
