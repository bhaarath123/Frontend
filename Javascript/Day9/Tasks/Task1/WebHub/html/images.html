HTML Images & Semantics

1. What is it?

Images in HTML are void elements defined with the tag. The figure (

2. Why is it important?

Visual graphics make layouts engaging. Alt text fallback ensures visually impaired users and search engine bots can index and understand your images.

3. Syntax & Basic Example

<figure>
  <img src="pic.jpg" alt="Descriptive text" width="300" height="200">
  <figcaption>Photo label caption.</figcaption>
</figure>

Basic description: A simple image tag: `<img src="logo.png" alt="WebLearn logo">`.

5. Line-by-Line Explanation

  • : Void tag (requires no closing tag) to display graphic assets.
  • alt attribute: Descriptive text for accessibility screen readers.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
src The relative path or URL of the image file.
alt Accessibility description, displayed if the image fails to load.
loading Set loading='lazy' to defer image loading until user scrolls close, improving speed.

7. Real-World Use

E-commerce sites wrap product listings in figures, showing details and captions aligned with the card image.

Best Practices

  • Always define width and height attributes in CSS or HTML to prevent layout shift during loading.
  • Use modern web graphic formats like WebP or AVIF.

Common Mistakes

  • Leaving alt descriptions blank (alt='') or writing useless summaries like 'photo.jpg'.
  • Using massive high-resolution camera files without scaling them, destroying mobile loading performance.

9. Tech Screening Question

Q: What is Cumulative Layout Shift (CLS) and how do image dimensions affect it?
Answer:

Cumulative Layout Shift (CLS) is a performance metric measuring visual stability. If you omit width/height attributes on images, the browser allocates 0px space initially. When the image loads, it suddenly pushes the content below it down. Defining dimensions reserves space beforehand, preventing shifts.

Explanation:

Reserving space stabilizes the page during lazy loading.

<img src='hero.jpg' alt='Hero' width='800' height='400'>

10. Quick Revision

Use img inside figure wrappers with figcaption. Always define alt text for screen readers and specify dimensions to minimize layout shifts.
