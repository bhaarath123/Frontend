HTML5 Accessibility

What is HTML5 Accessibility?

Accessibility (a11y) in web development means structuring code so that websites are usable by everyone, including people with physical, sensory, or cognitive impairments. HTML5 accessibility uses semantic code, form labels, alt tags, and keyboard focus controls.

Why is it used?

Accessibility is a moral, legal, and search ranking factor. Screen readers, voice inputs, and keyboard navigation rely directly on correct HTML semantics to browse pages.

Code & Output Example

html editor
<form action="#" style="font-family: sans-serif;">
    <fieldset style="border: 2px solid #6366f1; border-radius: 8px; padding: 15px;">
        <legend style="padding: 0 10px; font-weight: bold; color: #6366f1;">Accessibility Form</legend>
        <label for="acc_name" style="display: block; margin-bottom: 4px;">User Name (Announced by screen reader):</label>
        <input type="text" id="acc_name" aria-required="true" style="padding: 8px; border: 1px solid #ccc; width: 100%;">
    </fieldset>
</form>
Visual Preview
Accessibility Form

Code Explanation

  • & : Groups related fields together, providing screen readers with context descriptions.
  • aria-attributes: Accessible Rich Internet Applications properties that add metadata details (e.g. aria-label, aria-describedby).
  • for attribute: Syncs label with input, extending target clicking surface.

Important Points

  • Semantic elements have built-in default keyboard focus behaviors.
  • Ensure color contrast between text and background is high.
  • Interactive elements like links and buttons must show clear outline focuses when selected with the keyboard.

Common Mistakes

  • Using empty links like Click or using span elements instead of native buttons, which prevents tab navigation.
  • Leaving out alt attributes or using useless titles like alt='image'.

Real-World Usage

Government and enterprise sites must strictly adhere to WCAG (Web Content Accessibility Guidelines) standard levels (A, AA, AAA). Failing to do so can result in accessibility lawsuits and penalties.

Interview Question

Q: What is ARIA, and when should you use it?
Answer:

ARIA stands for Accessible Rich Internet Applications. It is a set of special HTML attributes (such as aria-label, role, aria-expanded) that add accessibility information to elements. You should use ARIA when native HTML tags cannot describe the component behavior (e.g. when building custom JS widgets, carousels, or tabs).
