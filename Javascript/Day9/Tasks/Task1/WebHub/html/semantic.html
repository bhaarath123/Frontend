Semantic HTML5 Elements

1. What is it?

Semantic HTML refers to using markup tags that describe the meaning of the content (like

2. Why is it important?

Semantic tags improve accessibility (screen readers use them as navigation landmarks), search engine indexing (bots crawl semantic elements to parse context), and code maintainability.

3. Syntax & Basic Example

<header>
  <nav>Links</nav>
</header>
<main>
  <article>Content</article>
</main>
<footer>Footer info</footer>

Basic description: A semantic article: `<article><h2>Topic</h2><p>Description</p></article>`.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
section A thematic grouping of content, usually with a heading.
article A self-contained block of content that can be reused independently (e.g. blog posts).
aside Content tangentially related to the surrounding text, usually styled as a sidebar.
