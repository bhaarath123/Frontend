Links & Relative Paths

1. What is it?

Links (hyperlinks) connect pages. Created with the anchor tag (), the href attribute defines the target directory path, target control options, and bookmark anchors.

2. Why is it important?

Links connect documents. Relative paths point to internal pages within a website, while absolute paths target external domains.

3. Syntax & Basic Example

<a href="target.html" target="_blank" rel="noopener">Link Text</a>

Basic description: Internal link: `<a href="pages/about.html">About Us</a>`.

4. Code & Interactive Rendered Output

<p>Browse <a href="https://www.google.com" target="_blank" rel="noopener">Google search</a> (Absolute link in new tab).</p>
<p>Contact us via <a href="mailto:support@site.com">Email support</a>.</p>

5. Line-by-Line Explanation

  • href='../index.html': Relative path that moves up one directory level to find the index file.
  • target='_blank': Opens the target webpage in a separate browser tab.
  • rel='noopener': Security setting for target='_blank' links to prevent security exploits (tabnabbing).

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
href Specifies destination path or protocol (mailto:, tel:, #).
target Controls target tab load behavior (_self, _blank).
rel Defines relation parameters (noopener, noreferrer).

7. Real-World Use

Navbars, sidebars, and call-to-action buttons use anchor tags to direct users through sites and funnel checkouts.

Best Practices

  • Use relative paths for internal site navigation to ensure pages link correctly across testing domains.
  • Write descriptive link copy (e.g. 'Download PDF' instead of 'Click Here').

Common Mistakes

  • Forgetting the href attribute, turning the tag into static plain text.
  • Omitting security rel attributes on external blank targets.

9. Tech Screening Question

Q: What is the security risk of target='_blank' and how is it resolved?
Answer:

When you link to an external page using target='_blank', the opened page gets access to the window object of your page via window.opener. This allows malicious external pages to redirect your original page to a phishing site. Adding rel='noopener' or rel='noreferrer' blocks this access.

Explanation:

Security compliance requires combining rel='noopener' with target='_blank'.

<a href='https://external.com' target='_blank' rel='noopener'>Link</a>

10. Quick Revision

Anchor tags connect web documents. Use relative paths for internal files, absolute paths for external sites, and always include rel='noopener' on target='_blank' links.
