Exercise 1: Responsive Columns Stack Intermediate
Question:

Create a 2-column grid that stacks on mobile and splits on desktop (md).

Starter Code:
<div class="row"></div>
Reveal Hint

Use col-12 col-md-6.

Reveal Solution 
<div class="row">
  <div class="col-12 col-md-6">Col 1</div>
  <div class="col-12 col-md-6">Col 2</div>
</div>
