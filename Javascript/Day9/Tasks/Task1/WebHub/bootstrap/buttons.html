Bootstrap Buttons

What is Bootstrap Buttons?

Bootstrap buttons are styled elements with preset actions. Standard buttons are styled with the base class .btn, combined with coloring classes (.btn-primary, .btn-secondary, etc.) and size variations.

Why is it used?

Buttons are primary UI triggers. Having predefined, unified styles for main actions, warnings, details, and disabled states ensures UI consistency.

Code & Output Example

bootstrap editor
<div class="d-flex gap-2">
    <button class="btn btn-primary">Primary</button>
    <button class="btn btn-outline-danger">Outline Danger</button>
    <button class="btn btn-warning btn-sm">Small Warning</button>
</div>
Visual Preview

Code Explanation

  • btn: The base class. Removes borders, adds block padding, handles cursor pointers, and sets default alignments.
  • btn-primary, btn-outline-danger: Pre-styled color classes for primary links and outlines.
  • btn-sm, btn-lg: Modifies element sizes.

Important Points

  • The .btn class can be applied to both
  • Disable actions by appending the disabled attribute to a button or the .disabled class to an anchor.
  • Anchor links styled as buttons must include role='button' for screen readers.

Common Mistakes

  • Using button classes without the primary .btn base class (e.g. class='btn-primary'), which removes all spacing and layout styling.
  • Applying button classes to random elements like div or span instead of native buttons or anchors, breaking keyboard access.

Real-World Usage

Sign-up forms, navigation buttons, e-commerce buy buttons, and card links all use these buttons. In custom themes, developers change brand colors by overriding Bootstrap variables.
