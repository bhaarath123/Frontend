Bootstrap Core Components

What is Bootstrap Core Components?

Bootstrap provides pre-styled UI components, including Alerts, Badges, Breadcrumbs, Pagination, Progress Bars, Spinners, Dropdowns, Accordions, Carousels, Modals, Offcanvas, and Toasts.

Why is it used?

Instead of writing complex CSS layouts and JS drawer bindings for elements like modals or accordions, developers use pre-styled Bootstrap classes and attributes.

Code & Output Example

bootstrap editor
<!-- Static Progress Bar & Spinner -->
<div class="mb-3">
    <div class="progress" style="height: 20px;">
        <div class="progress-bar bg-success" role="progressbar" style="width: 75%;" aria-valuenow="75" aria-valuemin="0" aria-valuemax="100">75% Complete</div>
    </div>
</div>
<div class="d-flex align-items-center gap-2">
    <div class="spinner-border text-info" role="status"></div>
    <span>Loading resource...</span>
</div>
Visual Preview
75% Complete
Loading resource...

Code Explanation

  • progress, progress-bar: Styled wrapper grids that display completion status.
  • spinner-border: Creates animated loading widgets natively with CSS transitions.
  • accordion, accordion-item: Layout groupings that toggle collapsible FAQ drawers.

Important Points

  • Many core components (Modal, Offcanvas, Accordion, Dropdown, Carousel) require Bootstrap's bundle JS to interact.
  • Use accessibility roles (role='progressbar', role='status') to announce updates to screen readers.
  • Colors can be changed across components using standard theme utilities (.bg-*, .text-*).

Common Mistakes

  • Forgetting to load Bootstrap’s bundle script file, preventing menus, modal drawers, and accordion dropdowns from expanding when clicked.
  • Omitting aria configurations, breaking screen-reader announcements on loading status components.

Real-World Usage

Product documentation sites build FAQs with accordions, dashboards display metrics using progress bars, and content portals handle action loads using spinners.

Interview Question

Q: Which Bootstrap components require JavaScript to function?
Answer:

Components that require JavaScript include Modals, Accordions, Dropdowns, Carousels, Offcanvas drawers, Toasts, Tooltips, and Popovers. These components rely on Bootstrap's JS engine to handle opening, closing, sliding, and position calculations.

Explanation:

If you only load Bootstrap's CSS file, these components will display on screen but will not change state or open when clicked.

A modal will remain hidden unless triggered via data attributes (data-bs-toggle='modal') linked to Bootstrap's JS file.
