Bootstrap Cards

What is Bootstrap Cards?

Bootstrap Cards are flexible content containers. They include options for headers, footers, images, titles, subtitles, text blocks, and navigation links, styled with a border, padding, and background surface.

Why is it used?

Cards organize structured info. They are perfect for displaying blog entries, shop products, team profiles, and dashboard metric widgets.

Code & Output Example

bootstrap editor
<div class="card" style="max-width: 300px;">
    <div class="card-header bg-indigo text-white" style="background-color: #6366f1;">
        Featured Topic
    </div>
    <div class="card-body">
        <h5 class="card-title">Learning Cards</h5>
        <p class="card-text" style="color: #666;">Cards contain clean structures for layouts.</p>
        <a href="#" class="btn btn-sm btn-primary">Select Item</a>
    </div>
</div>

Code Explanation

  • card: The main card wrapper. Adds borders, background color, and block structure.
  • card-body: Adds padding inside the card.
  • card-title, card-text: Standard formatting for titles and description content.
  • card-header, card-footer: Optional header and footer bars.

Important Points

  • Cards have 100% width by default; control width using grid columns or inline style attributes.
  • Use card-img-top or card-img-bottom to align images smoothly within the card borders.
  • Group multiple cards together using grid columns to build product catalogs.

Common Mistakes

  • Forgetting to wrap text nodes inside the .card-body container, which results in text touching the card borders with zero padding.
  • Nesting too many layers of cards inside each other, creating visual clutter.

Real-World Usage

E-commerce sites display product grids (image, name, price, buy button) using cards. Content blogs show article grids using cards with headers and footers.

Interview Question

Q: How do you control the width of a Bootstrap card?
Answer:

By default, a Bootstrap card expands to fill 100% width of its parent container. You can control its width either by wrapping it in a grid column (e.g.

), placing it inside a container with restricted sizing, or by defining an explicit width inline or in CSS.

Explanation:

Wrapping cards in responsive grid columns is the best practice for building clean grids.

<div class='col-sm-6 col-md-4'><div class='card'>...</div></div>
