Alerts & Core Components

1. What is it?

Bootstrap components are pre-styled elements. Alerts (.alert) display contextual notifications, badges (.badge) display counts, and breadcrumbs (.breadcrumb) indicate page hierarchy.

2. Why is it important?

Pre-styled warning boxes and notifications save time. Instead of coding spacing and borders, you apply alert classes to elements.

3. Syntax & Basic Example

<div class="alert alert-warning" role="alert">
  Warning notification message!
</div>

Basic description: A warning alert box: `<div class="alert alert-warning">Notice</div>`.

4. Code & Interactive Rendered Output

    <div class="alert alert-info mb-2" role="alert">

    </div>
    <span class="badge bg-secondary">New update</span>
</div>

Expected Layout / Behavior: A blue alert box with a highlighted link, followed by a grey badge badge tag below.

5. Line-by-Line Explanation

  • alert-info: Applies light blue styling indicating information.
  • alert-link: Styles links inside the alert to match the alert's text color.
  • badge bg-secondary: Styles text into a small pill-shaped badge with a grey background.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
alert Base alert box class that sets padding and border-radius.
alert-link Aligns colors of links inside alerts with the alert text.
badge Styles text into small badge labels, commonly used for notifications or counts.

7. Real-World Use

Websites use alerts to display status messages (like 'Profile Saved' or 'Validation Failed') at the top of forms.

Best Practices

  • Use appropriate contextual classes (danger, warning, success) matching status updates.
  • Use dismissible alert configurations so users can dismiss notifications.

Common Mistakes

  • Forgetting to add role='alert' to alert containers, which prevents screen readers from announcing warning messages to users.
  • Using alerts for layout containers.

9. Tech Screening Question

Q: Why should you add role='alert' to an alert box container?
Answer:

The role='alert' attribute is an ARIA accessibility configuration. It tells the browser that the container holds a critical warning message. When the alert appears on screen, the screen reader will interrupt its current announcement to read the alert text aloud to the user.

Explanation:

This ensures that dynamic error notifications are announced to visually impaired users.

<div class='alert alert-danger' role='alert'>Invalid Login!</div>

10. Quick Revision

Alerts (.alert) display warnings. Badges (.badge) display counts. Set role='alert' on alert containers to support screen-reader accessibility.
