CSS Responsive Design & Media Queries

What is CSS Responsive Design & Media Queries?

Responsive Web Design ensures that web pages look good on all devices (mobile, tablet, desktop). Media queries are CSS3 directives that apply style declarations only when conditions (like screen width) match.

Why is it used?

Mobile traffic represents over 50% of web visits. Media queries allow developers to transform multi-column desktop grids into single-column vertical lists on mobile.

Code & Output Example

css editor
<div class="responsive-card">
    <h3>Adaptive Block</h3>
    <p>Background shifts color based on viewport screen size.</p>
</div>
Visual Preview

Adaptive Block

Background shifts color based on viewport screen size. (Resize browser to test)

Code Explanation

  • @media: Specifies a media query directive block.
  • min-width: Breakpoint setting. Activates styles when the screen size is equal to or wider than the value.
  • max-width: Breakpoint setting. Activates styles on screens narrower than the value.
  • Mobile-First Design: Standard practice of writing mobile styles first and scaling up using min-width queries.

Important Points

  • Always set the viewport meta tag in your HTML head for media queries to trigger on mobile devices.
  • Breakpoints align with standard screen widths: Mobile (under 768px), Tablet (768px - 1024px), Desktop (above 1024px).
  • Avoid using too many custom breakpoints; stick to a consistent framework system.

Common Mistakes

  • Designing for desktop first and writing complex max-width overrides, leading to convoluted and buggy CSS files.
  • Defining fixed pixel widths (like width: 960px) on layout containers, causing content to overflow mobile viewports.

Real-World Usage

Modern CSS systems use grid systems that adapt fluidly. Breakpoints are used to switch grid configurations, hide/show sidebar drawers, and scale heading typography.

Practice Exercise

Write a media query that hides an element with class '.sidebar' when the screen width is less than 600px.

Objective: Configure visibility based on screen width.

Instructions: Use max-width media query containing display: none.

/* Add query selector below */
Reveal Hint

Use @media (max-width: 599px) and target .sidebar.

Reveal Solution 
@media (max-width: 599px) {
    .sidebar {
        display: none;
    }
}

Interview Question

Q: What is Mobile-First Design, and why is it recommended?
Answer:

Mobile-First Design is a design strategy where you write CSS styles for small screen devices (like mobile phones) as the default styles, and then use min-width media queries to add layout enhancements as the screen gets wider.

Explanation:

This is recommended because mobile styles are simpler. Starting simple leads to cleaner code, faster page loads on mobile data networks, and a more robust layout skeleton.

Default rules (mobile columns) -> @media (min-width: 768px) { grid-template-columns: 1fr 1fr } (desktop layout).
