CSS Variables (Custom Properties)

What is CSS Variables (Custom Properties)?

CSS Variables (officially Custom Properties) are entities defined by CSS authors that contain specific values to be reused throughout a document. They are declared using two dashes (--) and accessed using the var() function.

Why is it used?

Variables keep stylesheets organized. Instead of copy-pasting HEX colors hundreds of times, declaring a single variable allows you to change theme colors across the entire site by editing one value.

Code & Output Example

css editor
<div class="var-demo">
    <h4>Dynamic CSS Variables</h4>
    <p>Using root configurations for layout sizing.</p>
</div>

Code Explanation

  • :root: Pseudo-class that targets the highest root element (usually ), making variables global.
  • --variable-name: Declares a custom property. Must start with two dashes.
  • var(--name, fallback): Retrieves the value, with an optional fallback color value if the variable is not defined.

Important Points

  • CSS variables are dynamic: they can be updated in real-time using media queries or custom theme class overrides.
  • CSS variables inherit: a child element can override a parent's variable value locally.
  • Variables are case-sensitive.

Common Mistakes

  • Declaring variables without the double-dash prefix (e.g. primary-color: blue instead of --primary-color: blue).
  • Confusing CSS variables with Sass/SCSS variables, which are compiled offline and cannot change dynamically in the browser.

Real-World Usage

Most modern themes, including dark mode implementations, are powered by CSS variables. Changing the variables inside a body.dark selector automatically swaps the colors of all elements on the page.

Practice Exercise

Declare a local variable '--text-size' with value '22px' inside a '.large-text' class, and apply it to the font-size of that selector.

Objective: Declare and load local CSS custom properties.

Instructions: Apply local variable declaration and var load.

.large-text {
    /* Style here */
}
Reveal Hint

Use --text-size: 22px; and font-size: var(--text-size);.

Reveal Solution 
.large-text {
    --text-size: 22px;
    font-size: var(--text-size);
}

Interview Question

Q: How do CSS Custom Properties differ from preprocessor variables (like Sass)?
Answer:

CSS Custom Properties (CSS variables) are native browser properties. They are dynamic, meaning they can change in the browser (e.g., inside media queries or theme overrides) and can be accessed by scripts. Preprocessor variables (like Sass or Less) are compiled into static CSS values before shipping to the browser, meaning they do not exist in runtime.

Explanation:

Native CSS variables are much more powerful for building run-time themes like Dark Mode.

Sass: $color: red; (outputs 'color: red' to browser). Native: --color: red; (retains var reference in browser stylesheet).
