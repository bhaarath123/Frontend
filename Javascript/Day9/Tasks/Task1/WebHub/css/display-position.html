Display, Overflow & Positioning

1. What is it?

Display properties (block, inline, inline-block, none) control how elements layout. Position properties (static, relative, absolute, fixed, sticky) offset elements relative to their containers or page viewports.

2. Why is it important?

Controlling layouts is critical. Absolute coordinates overlay menus, sticky positions lock headers during scrolling, and inline blocks place buttons side-by-side.

3. Syntax & Basic Example

.navbar {
  position: sticky;
  top: 0;
  z-index: 100;
}
.popup {
  position: absolute;
  top: 50%;
  left: 50%;
}

Basic description: Locking header on top: `position: fixed; top: 0;`.

5. Line-by-Line Explanation

  • position: sticky: Keeps the header locked to the top when scrolling within the container.
  • position: relative: Establishes a coordinate boundary for absolute child tags.
  • position: absolute: Places the badge at the top-right corner of the parent container.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
z-index Sets layer stack orders; higher values display on top of lower values.
overflow Configures scroll behavior when content exceeds element boundaries (visible, hidden, scroll, auto).
display: none Hides the element and removes it from the page layout flow.

7. Real-World Use

E-commerce sites use position: absolute to overlay sales badges on images, and use position: sticky to lock navigation bars to the top when scrolling.

Best Practices

  • Avoid hardcoding absolute values when grid or flexbox positioning is better suited.
  • Use sticky navigation bars to improve website usability.

Common Mistakes

  • Using position: absolute without declaring position: relative on the parent container, causing the child to position relative to the root body instead.
  • Setting high z-index values on unrelated elements, causing display issues with modal layouts.

8. Interactive Practice Challenge

Style a pop-up window '.popup' to have a fixed position, centered in the screen vertically and horizontally with a high stack order.

Objective: Work with absolute/fixed coordinates.

Instructions: Set position, top, left, transform, and z-index properties.

.popup {
  /* Add positioning rules */
}
Reveal Hint

Use position: fixed, top: 50%, left: 50%, and transform: translate(-50%, -50%).

Reveal Solution 
.popup {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
  z-index: 1000;
}

9. Tech Screening Question

Q: What is the difference between relative, absolute, and fixed positioning?
Answer:

Relative positioning offsets the element from its normal document position without affecting surrounding elements. Absolute positioning removes the element from the document flow and positions it relative to its closest positioned ancestor. Fixed positioning removes the element from the flow and positions it relative to the browser viewport, keeping it locked in place during scrolling.

Explanation:

Position relative anchors absolute child coordinates; fixed anchors elements to the viewport screen.

Sticky navbar: sticky or fixed. Card icon overlay: absolute.

10. Quick Revision

Use display to set block behaviors. Use relative parent containers to anchor absolute children, and z-index to manage overlapping layers.
