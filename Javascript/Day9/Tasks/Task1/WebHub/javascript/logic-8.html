Logic Problem 8 of 10

Find Sum of Digits of a Number

Problem Statement

Write a JavaScript function that calculates the sum of all individual digits in a given positive integer.

Examples

Example 1:
Input: num = 12345
Output: Sum of digits is 15 (1 + 2 + 3 + 4 + 5)
Example 2:
Input: num = 908
Output: Sum of digits is 17 (9 + 0 + 8)

Logic & Thought Process

We can extract digits mathematically using modulo 10 (`num % 10`) to get the last digit, and integer division by 10 (`Math.floor(num / 10)`) to remove the last digit until the number reaches 0. Alternatively, convert the number to string, split into character digits, and accumulate using `.reduce()`.

Step-by-Step Algorithm

  1. Step 1: Start the program.
  2. Step 2: Read input integer `num` (use `Math.abs(num)` to handle negative inputs).
  3. Step 3: Initialize `sum = 0`.
  4. Step 4: While `num > 0`:
  5. a. Extract last digit: `digit = num % 10`.
  6. b. Add to sum: `sum += digit`.
  7. c. Remove last digit: `num = Math.floor(num / 10)`.
  8. Step 5: Return `sum`.
  9. Step 6: End.

JavaScript Solution Code

// Mathematical Digit Extraction
function sumOfDigits(num) {
  let n = Math.abs(num);
  let sum = 0;

  while (n > 0) {
    sum += n % 10;           // Extract last digit
    n = Math.floor(n / 10);  // Remove last digit
  }

  return sum;
}

// Alternative functional approach:
// const sumDigitsStr = n => Math.abs(n).toString().split('').reduce((acc, d) => acc + Number(d), 0);

// Test cases
console.log(sumOfDigits(12345)); // 15
console.log(sumOfDigits(908));   // 17

Output: Extracts digits 5, 4, 3, 2, 1 successively and accumulates their sum: 5 + 4 + 3 + 2 + 1 = 15.

Line-by-Line Code Explanation

  • Line 2: `let n = Math.abs(num)` guarantees positive values.
  • Line 3: `let sum = 0` initializes accumulator variable.
  • Line 5: `while (n > 0)` continues as long as digits remain.
  • Line 6: `n % 10` extracts the rightmost digit and adds to sum.
  • Line 7: `Math.floor(n / 10)` strips the rightmost digit.
  • Line 10: Returns final calculated sum.
Complexity Analysis

Time Complexity: O(D) - Where D is the number of digits in the integer (equivalent to O(log10 N)).

Space Complexity: O(1) - Constant space.

Edge Cases & Interview Tips

Single digit numbers like 7 return 7. Negative numbers (e.g. -45) have digits summed as 4 + 5 = 9 using Math.abs.
