Logic Problem 2 of 10

Find Largest of Three Numbers

Problem Statement

Write a JavaScript program that accepts three numbers and returns the greatest (maximum) among them.

Examples

Example 1:
Input: a = 25, b = 78, c = 42
Output: 78 is the largest number
Example 2:
Input: a = 90, b = 15, c = 30
Output: 90 is the largest number

Logic & Thought Process

To find the largest of three numbers `a`, `b`, and `c`, we can compare `a` with both `b` and `c` using the logical AND (`&&`) operator. If `a >= b` and `a >= c`, then `a` is the largest. Otherwise, if `b >= c`, then `b` is the largest. If neither condition holds, `c` must be the largest. Alternatively, JavaScript provides `Math.max(a, b, c)`.

Step-by-Step Algorithm

  1. Step 1: Start the program.
  2. Step 2: Read three numbers `a`, `b`, and `c`.
  3. Step 3: If `(a >= b && a >= c)`, then `largest = a`.
  4. Step 4: Else if `(b >= a && b >= c)`, then `largest = b`.
  5. Step 5: Else, `largest = c`.
  6. Step 6: Return the largest number.
  7. Step 7: End.

JavaScript Solution Code

function findLargestOfThree(a, b, c) {
  if (a >= b && a >= c) {
    return `${a} is the largest number`;
  } else if (b >= a && b >= c) {
    return `${b} is the largest number`;
  } else {
    return `${c} is the largest number`;
  }
}

// Built-in alternative: Math.max(a, b, c)
const largestBuiltin = (a, b, c) => Math.max(a, b, c);

// Test cases
console.log(findLargestOfThree(25, 78, 42)); // "78 is the largest number"
console.log(findLargestOfThree(90, 15, 30)); // "90 is the largest number"

Output: Compares 25, 78, and 42. Since 78 >= 25 and 78 >= 42, it returns '78 is the largest number'.

Line-by-Line Code Explanation

  • Line 1: Function declaration accepting three numeric arguments `a`, `b`, and `c`.
  • Line 2: Checks if `a` is greater than or equal to both `b` and `c` using `&&`.
  • Line 3: If true, returns `a` as the largest.
  • Line 4: Else if `b` is greater than or equal to both `a` and `c`, returns `b`.
  • Line 6: If neither is true, `c` is guaranteed to be the largest.
Complexity Analysis

Time Complexity: O(1) - Constant time complexity with a maximum of 2 comparisons.

Space Complexity: O(1) - Constant auxiliary space.

Edge Cases & Interview Tips

When all three numbers are equal (e.g. 5, 5, 5), `>=` ensures the condition evaluates correctly without errors.
