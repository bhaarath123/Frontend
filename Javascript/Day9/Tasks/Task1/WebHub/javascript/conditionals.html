Conditional Statements

1. What is it?

Conditional statements are used to perform different actions based on different logical conditions. JavaScript supports `if`, `if-else`, `else if` ladders, nested `if`, and `switch` statements.

2. Why is it important?

Programs need decision-making logic. Conditionals allow websites to show personalized greetings, calculate grades, validate passwords, and control application flow.

3. Syntax & Basic Example

// if - else if - else
if (score >= 90) {
  grade = "A";
} else if (score >= 80) {
  grade = "B";
} else if (score >= 70) {
  grade = "C";
} else {
  grade = "F";
}

// switch statement
switch (dayNumber) {
  case 1: dayName = "Monday"; break;
  case 2: dayName = "Tuesday"; break;
  default: dayName = "Other Day";
}

Basic description: Even or odd check: `if (num % 2 === 0) { console.log('Even'); } else { console.log('Odd'); }`

5. Line-by-Line Explanation

  • `if (condition)` executes the block if the condition evaluates to truthy.
  • `else if (condition)` tests a secondary condition if the previous condition was falsy.
  • `else` executes when all preceding conditions are falsy.
  • `switch (expression)` compares the expression against multiple `case` values using strict equality (`===`).
  • `break` statement inside a switch terminates the switch block, preventing 'fall-through' execution into subsequent cases.
  • `default` specifies the fallback code to run if no case matches.

6. Key Properties, Methods & Syntax

Property / Method / Tag Description
if...else Primary conditional branch structure in JavaScript.
switch Multi-branch statement best suited when comparing one variable against multiple exact values.
break Jumps out of the switch block to prevent fall-through.
default Default fallback block in a switch statement if no cases match.

7. Real-World Use

Authentication middlewares check `if (!user.isLoggedIn) { redirectToLogin(); }` to protect dashboard pages.

Best Practices

  • Use `if-else` for range checks (`score >= 80`) and `switch` for specific discrete values (e.g. `status === 'PENDING'`, `'ACTIVE'`, `'CANCELLED'`).
  • Keep nested `if` statements shallow (max 2 levels) to maintain code readability.

Common Mistakes

  • Forgetting `break` in a `switch` statement, which causes the browser to execute all subsequent cases regardless of their condition (fall-through).
  • Using assignment (`=`) instead of comparison (`===`) in the `if` condition.

9. Tech Screening Question

Q: When should you use `switch` instead of `if-else`?
Answer:

Use `switch` when you are evaluating a single variable against multiple discrete, constant values (like menu options, status codes, or days of the week). Use `if-else` when you are evaluating boolean conditions, ranges (e.g., `x > 10 && x < 20`), or multiple different variables.

Explanation:

Switch statements use strict comparison (`===`) and make multi-value branching cleaner to read.

switch (action) { case 'ADD': ... break; case 'DELETE': ... break; }

10. Quick Revision

Use `if`, `else if`, and `else` for condition branching. Use `switch` for multi-value discrete matching with `break` to prevent fall-through.
